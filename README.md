# Casa Lumbre

Landing de una sola página para el restaurante. HTML, CSS y JavaScript sin frameworks.

## Dónde editar

Todo lo que cambia con el local está en [`js/datos.js`](js/datos.js): nombre, frase, historia, carta, precios, teléfono, WhatsApp, dirección, horarios, mapa y redes.

Los precios se escriben como número entero (`46000` se muestra `$46.000`). Las fotos van en `assets/fotos/`.

Para verla en local:

```bash
python3 -m http.server 8765
```

Abre `http://localhost:8765`.
